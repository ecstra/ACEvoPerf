# What the mod costs in frame rate, 2026-10-16

A player with a 2070 on triple 1080p screens read 87 fps parked in the pits without the mod and 77 to 82 with
it. To answer it without asking him for more runs, the owner drove four one minute pit box runs on the
reference laptop with the usual car and track, each recorded with PresentMon 2.5.1 and the `nvidia-smi`
sampler. Logs in `logs/mod-cost-20261016`. The figures are the last 50 s parked of each launch.

| run | fps | GPU busy per frame | CPU busy per frame | GPU clock | GPU temp | game's own pools |
|---|---|---|---|---|---|---|
| no mod (Steam verified) | 95.8 | 10.44 ms | 7.36 ms | 1687 MHz | 75 C | texture 405 MB, mesh 405 MB |
| mod, defaults | 90.1 | 11.22 ms | 8.43 ms | 1665 MHz | 74 C | texture 1024 MB, mesh 1433 MB |
| mod, `responsive_ui=0` | 91.7 | 11.00 ms | 8.22 ms | 1702 MHz | 74 C | texture 1024 MB, mesh 1433 MB |
| mod, pool flags off | 95.0 | 10.53 ms | 7.97 ms | 1822 MHz | 67 C | texture 1122 MB, mesh 1122 MB |

What it shows:

- Every run was `Hardware: Independent Flip`. The mod does not push the game through the compositor on this
  machine, so the player's all `Composed: Flip` capture is not explained by the mod. PresentMon reports
  composed whenever the game is not the focused window, which a command prompt left in front would do.
- The first two rows ran at the same temperature and clock, and the mod adds about 0.8 ms of graphics card
  work per frame, the whole 6 percent. Without the mod the game cut its own texture pool from 1024 to 405 MB
  and its mesh budget to 405 MB when the track loaded, the mushy texture bug, so it drew far less detail.
- The responsive UI costs nothing measurable, its run sits on the default mod's GPU work per frame. The extra
  CPU busy time with the mod is Reflex's sleep, which PresentMon counts between presents. The CPU is not the
  limit in any run.
- With the pool flags off the game's own formula picked bigger pools than without the mod, 1122 MB each,
  because the mod's staging buffer cap leaves it more video memory. That run ran 7 C cooler at a 9 percent
  higher clock, so its frame rate is not comparable with the others. Scaled by clock its GPU work per frame
  is the highest of the four, which fits more texture detail costing more.

So on this machine the mod's frame rate cost is the price of the detail it keeps, sharper textures and full
mesh levels, against a game that would otherwise drop to 405 MB pools. Thermal state moves the clock by as
much as the effect, so single runs on the laptop only compare when their temperatures match.
